5. Bot Safety Risks

Trading bots can contain bugs, malware, or logic errors that cause unexpected losses. Risks include but are not limited to:

  • Opening positions far larger than intended due to lot-sizing bugs.
  • Failure to apply stop-loss orders correctly.
  • Trading during news events when spreads are widest.
  • Sending API keys to a third-party server without your knowledge.
  • Compromised .ex4/.ex5 files containing malicious code.

Use reputable antivirus software, run bots in isolated environments where possible, and never enter API keys with withdrawal permissions into any tool you have not verified.
